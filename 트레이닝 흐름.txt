1. 홈 화면 (training_home_screen.dart)
1) 상단 헤더 섹션

내 현재 티어 / 요약 정보 보여주는 영역

dao_tier_badge_large.dart
→ 현재 DaoTrainingTier(비기너/러너/…)를 큰 배지 스타일로 표시

최근 세션/레벨 테스트 결과 기반으로

“내 타겟 티어”

“Phoenix/Live 레이팅 기반 DAO 티어”
같은 값도 여기 묶일 수 있음 (티어 계산은 dao_training_rating_utils.dart에서)

배경/카드 자체는

neon_glow_container.dart나

AppCard
이런 걸 사용해서 네온/카드 스타일로 감싸는 역할

2) 네온 게이지 섹션

최근 지표 요약을 보여주는 부분

예: “최근 히트률 / 최근 PPD” 같은 거

dual_neon_gauge_row.dart

좌/우 두 개 지표를 네온 게이지로 표현하는 용도

여기에서 사용하는 값은:

training_history_provider 또는

training_home_provider가 최근 세션들을 요약해서 제공

3) 오늘의 추천 연습 섹션

타이틀: “오늘의 추천 드릴”, “Today’s Recommendation” 같은 헤더

리스트 아이템:

training_recommendation_card.dart

드릴 이름, 카테고리(예: Scoring, Finish), 예상 시간, 난이도 등을 카드로 표현

데이터 흐름:

training_home_provider → 현재 티어/최근 기록 기반으로

recommendedDrillsForToday(tier) (training_drill_constants.dart) 호출해서 리스트 만들고

training_home_screen이 그걸 training_recommendation_card로 렌더링

카드를 탭하면 → DrillRunScreen 으로 이동 (이미 구현되어 있음)

4) 히스토리/기록 섹션 (요약 영역)

홈 하단이나 중간쯤에:

“최근 연습 히스토리” 미리보기

최근 N개의 세션 간단 요약 (날짜, 드릴명, 성취도 등)

이 요약 블럭은:

전체 화면 training_history_screen.dart 로 들어가기 위한 진입 링크/버튼 역할

2. 티어/레벨 입력 쪽
2-1. training_rating_input_screen.dart

역할:
“피닉스 레이팅 / 라이브 레이팅을 입력해서 DAO 트레이닝 티어를 계산/저장”

상단: 안내 텍스트

“현재 사용 중인 레이팅을 입력하면 DAO 티어를 자동 계산합니다” 같은 문구

중간: 입력 폼

Phoenix 레이팅, Live 레이팅, MPR/PPD 같은 값 입력 필드

하단:

“티어 계산” / “저장” 버튼

버튼 누르면 dao_training_rating_utils.dart 호출

Phoenix/Live 레이팅 → DaoTrainingTier로 변환

이 결과를 사용자 문서 혹은 로컬 상태에 저장

이 화면에서 확정된 티어가:

training_home_screen에서 티어 뱃지 / 추천 드릴에 사용됨

2-2. board_level_test_screen.dart

역할:
“레이팅 없는 사람용 / 감각 기반 레벨 테스트”

상단: 테스트 설명

“보드 영역/숫자/더블 감각 테스트로 DAO 티어를 추정합니다”

중앙: 테스트 진행 UI

여기서 beginner_board_area_widget.dart 같은 걸 이용해서

보드 4분할, 상/하 영역, 특정 번호 강조
이런 시각 요소를 보여주게 설계

하단:

테스트 결과 (점수 or 점수 구간)

그 결과를 DaoTrainingTier에 매핑 (역시 dao_training_rating_utils.dart 해당 함수 사용)

결과 저장:

이 테스트로 나온 티어를

사용자 프로필 / 트레이닝 설정에 저장
→ 홈 화면/추천 드릴에 반영

3. 드릴 관련 ? 모델/상수/레포
3-1. training_drill_model.dart

역할:
“드릴 1개를 데이터 구조로 정의”

예: TrainingDrillDefinition, DrillTierRange, TrainingDrillCategory, TrainingDrillInputMode, DrillUIPattern 등

각각 필드:

id, titleKo, shortDescriptionKo, category, tierRange

inputMode (hitCount, scoreOnly, cricketMarks)

uiPattern (boardArea, segmentTarget, scoreGame, cricketMarks, checkoutRoute)

extraConfig (라운드 수, 다트 수, 타깃 범위 등)

?? 이 파일은 “드릴 설계 언어” 라고 보면 됨.
(우리가 상수 테이블에서 이 구조에 맞춰 정의하는 중)

3-2. training_session_model.dart

역할:
“실제 유저가 한 번 연습한 기록(세션) 구조”

필드 예:

userId, drillId, tierAtThatTime

inputMode, totalRounds, totalDarts

hitCount, totalMarks, totalScore

파생값 (성공률, PPD, MPR 등)

createdAt (타임스탬프)

extra (추가 디테일: finishedEarly, plannedRounds 등)

?? Firestore training_sessions 컬렉션에 저장/로드할 때 사용.

3-3. training_drill_constants.dart

역할:
“DAO 트레이닝의 모든 드릴 컨텐츠 테이블”

Beginner ~ Master까지 티어별 드릴 정의

예:

Beginner용: 보드 4분할, 상/하 영역, S20 큰 싱글, 느슨한 Count-Up

Learner용: S20 100발, 상/하 심화, 20↔19 스위치, …

Competitor~Master:

T20 100발/120발, Double Clock, 40?80 체크아웃, MPR 드릴, 170 루트 등

최종적으로

kTrainingDrillsByTier 맵에

DaoTrainingTier → List<TrainingDrillDefinition> 로 정리

getDrillsForTier(tier)

recommendedDrillsForToday(tier) 로 외부에 제공

?? 홈/추천/프로그램/히스토리 등에서 **“어떤 드릴이 어떤 티어에게 맞는가”**를 알 때 이걸 씀.

3-4. training_program_constants.dart

역할:
“4주 코스 같은 ‘훈련 프로그램’ 정의”

TrainingProgramDefinition

id, titleKo/En, descriptionKo/En

minTier, maxTier

drills: 이 프로그램에 포함된 드릴 리스트

recommendedSessionsPerWeek: 예) 3회 / 4회

예시:

beginnerProgram : 비기너 4주 기본 코스

learnerProgram : 러너 4주 루트 이해 코스

getProgramsForTier(tier):

해당 티어 유저에게 보여줄 수 있는 프로그램 필터링

?? 추후 UI에서 “프로그램 탭” 만들 때,
각 프로그램을 “코스 카드 + 포함 드릴 리스트”로 보여주고, 순서대로 수행하게 만들 수 있는 기반.

4. 저장/불러오기 레이어
4-1. training_repository.dart

역할:
“트레이닝 기능을 위한 리포지토리 인터페이스”

제공 메서드 예:

세션 시작/완료

세션 목록 조회 (기간/티어/드릴로 필터)

오늘/이번 주 통계

구현체를 바꿀 수 있게 인터페이스만 정의 (DI/테스트용)

4-2. training_repository_impl.dart

역할:
“실제로 Firestore에 연결해서 구현한 리포지토리”

Firestore 컬렉션 예:

training_sessions

책임:

startSession() → 새 세션 문서 생성 or 준비

finishSession() → 결과 필드 채워서 업데이트

fetchSessionsForUser(...) → 히스토리/통계용 목록 조회

Provider/화면들은 Firestore를 직접 모르게 하고, 전부 이 레포를 통해 접근

5. 상태 관리 Provider들
5-1. training_drill_provider.dart

역할:
“지금 진행 중인 드릴 세션 상태”

현재:

activeSession (Firestore에 생성된 세션 문서 정보)

세션 시작/종료 시 호출되는 메서드:

startSession(userId, drill, tierAtThatTime)

finishSession(...)

clearSession()

DrillRunScreen이 이 프로바이더를 사용:

첫 입력 시 _ensureSessionStarted() → startSession 호출

마지막에 _finishDrill() → finishSession 호출

화면 나갈 때/결과 화면 후 정리 → clearSession

5-2. training_history_provider.dart

역할:
“히스토리 리스트 / 필터 / 통계”

하는 일:

현재 로그인 유저의 세션 목록 불러오기

날짜/드릴/티어 기준으로 필터

간단 통계 (최근 n일 평균 성공률, PPD, MPR 등) 계산

training_history_screen.dart, training_session_detail_screen.dart 에서 사용:

스크린에서는 “화면 표현”에 집중

데이터 로드는 프로바이더가 담당

5-3. training_home_provider.dart

역할:
“트레이닝 홈에 필요한 데이터 묶음”

예:

현재 DAO 티어 (DaoTrainingTier)

오늘의 추천 드릴 리스트 (티어 기준)

최근 세션 일부 (홈에서 미리보기)

오늘/이번주 간단 통계 (성공률/PPD/MPR 등)

training_home_screen.dart에서 구독:

상단 헤더 / 게이지 / 추천 리스트 / 히스토리 미리보기를 한 번에 그림

6. 드릴 진행/결과/히스토리 화면
6-1. drills/drill_run_screen.dart

이건 아까 상세 설명했으니 짧게만 정리:

홈에서 추천 드릴 카드 눌렀을 때 → 이 화면으로 이동

inputMode에 따라 UI 패턴 분기:

hitCount: 성공/실패 버튼

scoreOnly: RoundInputPanel로 라운드 점수 입력

cricketMarks: RoundInputPanel로 마크 입력

상단: 드릴 정보 카드

중간: 진행 현황, 라운드 표시, 입력 UI

하단: 완료/종료 버튼

저장 시: training_drill_provider를 통해 Firestore에 세션 저장 → drill_result_screen으로 이동

6-2. drills/drill_result_screen.dart

역할:
“방금 끝낸 세션 결과 요약 화면”

보통 구성:

상단: 드릴 제목 + 완료 날짜/시간

중앙: 주요 지표

히트 모드: 시도 수, 성공 개수, 성공률

스코어 모드: 총 점수, PPD, 3다트 평균

크리켓: 총 마크, 평균 MPR

여기서 drill_stat_summary.dart 같은 위젯 사용

하단:

“오늘의 다른 추천 연습 보기”

“히스토리로 이동”

“같은 드릴 다시 시작” 버튼 등이 들어갈 수 있는 자리

6-3. history/training_history_screen.dart

역할:
“전체 트레이닝 히스토리 리스트 화면”

섹션 구성:

상단 필터/요약

기간 필터 (최근 7일, 30일 등)

드릴/카테고리 필터 (Scoring, Finish, Bull, Double 등)

티어 필터 (원하면)

메인 리스트

각 세션당:

날짜/시간

드릴 이름

간단 결과 (예: 성공률 %, PPD, MPR, 총 점수 등)

리스트 아이템 탭 → training_session_detail_screen으로 이동

(선택) 상단 요약 블럭

이 기간 동안:

총 세션 수

평균 PPD/MPR

가장 많이 한 드릴 등

데이터는 전부 training_history_provider에서 공급.

6-4. history/training_session_detail_screen.dart

역할:
“세션 하나를 깊게 보는 화면”

섹션:

상단 기본 정보

드릴 이름, 카테고리, 티어, 날짜/시간

메인 통계 영역

drill_stat_summary.dart 사용:

성공률, 시도수, 히트 수, PPD, MPR 등 세션 타입에 맞는 수치

부가 정보

계획된 라운드 vs 실제 진행 라운드

finishedEarly 여부

추가 메모, 코멘트(나중에 붙일 수 있음)

(앞으로 확장 가능)

이 드릴의 세션들을 시계열 그래프로 보여주는 탭 등
