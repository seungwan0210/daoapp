1️⃣ Beginner (비기너) – 6개
1. 4분할 감각 만들기
beginner_quadrant_basic
•	목적
보드를 4구역(우상/우하/좌하/좌상)으로 나눠 방향·거리 감각 만들기
•	구현 설정
o	inputMode: hitCount
o	uiPattern: boardArea
o	extraConfig
	mode: 'quadrant'
	rounds: 20R
	dartsPerRound: 3 → 총 60발
	successTarget: 15 (기준 값, 나중에 조정 가능)
	보드 이미지 + 4색(빨/노/초/파)로 영역 표시
•	진행 / 기록
o	앱이 “우상단 / 우하단 / 좌하단 / 좌상단” 순서로 지시 (색으로도 표시)
o	각 색당 15발씩 던진다고 보면,
	5R × 4구역 = 20R
o	5R(=15발)마다, 해당 색(구역)에 맞은 횟수 기록
	예) 빨강 15발 중 7발 → 성공률 % 계산
o	색별로:
	빨강: 성공 횟수 + %
	노랑: 성공 횟수 + %
	초록: 성공 횟수 + %
	파랑: 성공 횟수 + %
o	라운드 단위로는 0~3 히트 입력, 색(15발 단위) 기준으로 %를 보여줌

2. 상단/하단 영역 익히기
beginner_top_bottom_basic
•	목적
상단 vs 하단 큰 영역의 방향 감각 만들기
•	구현 설정
o	inputMode: hitCount
o	uiPattern: boardArea
o	extraConfig
	mode: 'top_bottom'
	totalDartsPerArea: 30 (상단 30, 하단 30 → 총 60발)
	dartsPerRound: 3 기준, 20R 사용 (설명상 20R 명시)
	보드 이미지에 상단/하단 영역 색상 표시
	예: 상단=빨강, 하단=노랑
•	진행 / 기록
o	상단 30발 → 하단 30발
o	라운드별로 해당 영역 히트 수(0~3) 입력
o	상단 30발 기준:
	빨강 영역에 맞은 총 횟수 + 상단 성공률 %
o	하단 30발 기준:
	노랑 영역에 맞은 총 횟수 + 하단 성공률 %

•	inputMode: hitCount
•	uiPattern: segmentTarget
•	extraConfig
o	segments: ['T20']
o	totalDarts: 60
o	rounds: 20R (3발 × 20R = 60발)

•	매 라운드 끝날 때:
o	이번 3발 중 T20 맞춘 개수 (0~3) 입력
•	세션 종료 후 앱에서:
o	전체 T20 개수 / 60 = 성공률 % 표시
