1. 설정 / 상수
training_drill_constants.dart

역할:

“D16 8라운드”, “불 50개 맞추기” 같은 개별 드릴 정의 목록.

드릴 ID, 이름, 설명, 라운드 수, 다트 수, 목표 텍스트 등 드릴 메타데이터 테이블.

training_program_constants.dart

역할:

Beginner/Challenger 같은 티어별로
“오늘 추천 프로그램: 드릴 A → 드릴 B → 드릴 C” 이런 훈련 프로그램(세트) 정의.

홈에서 보여줄 권장 루틴, “추천 패키지” 같은 구성 사용.

2. 공용 유틸 / 레이팅 로직
dao_training_rating_utils.dart

역할:

DAO 트레이닝 7티어 enum(DaoTrainingTier) 정의.

phoenix / live 레이팅 → DAO 티어로 변환 로직.

티어의 한글/영문 라벨, 색상, 설명 등 표시용 유틸.

3. 데이터 계층 (Repository & Model)
training_repository.dart

역할:

트레이닝과 관련된 기능의 추상 인터페이스.

예:

레이팅 프로필 불러오기/저장

세션 시작/종료/조회

최근 세션 목록 가져오기

실제 구현은 모름(Impl가 담당), 상위 레이어는 Firestore를 모르고 이 인터페이스만 사용.

training_repository_impl.dart

역할:

Firestore를 실제로 호출하는 구현체.

컬렉션 구조:

/trainingProfiles/{userId}

/users/{userId}/trainingSessions/{sessionId}

위에 정의한 Repository의 메서드를 Firestore read/write로 실제 실행.

training_drill_model.dart

역할:

드릴 정의용 모델 (TrainingDrillDefinition)

ID, 제목, 설명, 라운드 수, 다트 수, 카테고리 등.

드릴 카테고리 enum (TrainingDrillCategory)

boardMapping / finish / doublePractice / scoring / bull / other 같은 분류.

training_session_model.dart

역할:

실제로 유저가 연습한 세션 기록 데이터 모델.

포함 내용:

userId, drillId, drillTitle

startedAt / endedAt

totalAttempts, successCount, failCount, hitRate

extra(드릴별 커스텀 정보: 조기 종료 여부, 계획 라운드 수 등)

Firestore <-> 앱 간 toJson / fromJson 변환 담당.

4. 상태 관리 (Providers)
training/training_drill_provider.dart

역할:

현재 진행 중인 드릴 세션 상태 관리.

기능 예:

startSession() → Firestore에 세션 문서 만들고 activeSession 유지.

finishSession() → 성공/실패/시도수/extra 저장 후 세션 종료.

clearSession() → 화면 떠날 때 activeSession 정리.

DrillRunScreen과 DrillResultScreen에서 직접 사용하는 핵심 provider.

training/training_history_provider.dart

역할:

Firestore에서 최근 트레이닝 세션 목록을 가져오는 provider.

예: trainingRecentSessionsProvider
→ TrainingHistoryScreen에서 List<TrainingSessionModel> 표시용.

training/training_home_provider.dart

역할:

트레이닝 홈 화면에 필요한 대시보드 데이터/추천 정보 상태 관리.

예:

내 현재 DAO 티어 / phoenix & live 레이팅 프로필 가져오기.

오늘의 추천 드릴/프로그램 목록.

최근 기록 일부 통계(총 연습 다트 수, 최근 세션 hitRate 요약 등).

5. 화면 (Screens)
training_home_screen.dart

역할:

트레이닝 탭의 메인 홈 화면.

보여주는 것들(구현 의도):

내 DAO 티어 / 레이팅 카드

“오늘의 추천 드릴/프로그램” 카드들

“히스토리 보기”, “레이팅 입력”, “레벨 테스트”로 가는 진입 버튼.

training_rating_input_screen.dart

역할:

유저가 피닉스 / 라이브 레이팅, MPR/PPD 등을 직접 입력하는 화면.

입력값 → dao_training_rating_utils로 티어 계산 →
/trainingProfiles/{userId}에 저장.

저장 후 홈/다른 화면에서 현재 내 트레이닝 티어/레벨 표시.

board_level_test_screen.dart

역할:

레이팅이 없는 유저를 위해 숫자 맞추기/보드 테스트 형식의 레벨 테스트 화면.

테스트 결과를 기준으로 임시 DAO 티어/보드 레벨 산출.

결과를 trainingProfiles에 반영하거나, 드릴 추천에 사용.

6. 드릴 실행 / 결과 화면
drills/drill_run_screen.dart

역할:

선택한 드릴 1개에 대해 실제 연습을 진행하는 화면.

기능:

ROUND / DART 진행 표시.

“성공 / 실패” 버튼으로 결과 입력.

시도 수, 성공/실패 카운트, 성공률 실시간 표시.

조기 종료 시 finishedEarly 플래그 포함해 세션 저장.

trainingDrillProvider를 통해 Firestore 세션 생성/완료.

drills/drill_result_screen.dart

역할:

방금 끝난 세션의 요약 결과 화면.

보여주는 내용:

드릴 제목, 티어 배지(DAO TIER · MASTER 등)

성공률 % / 성공 다트 / 총 시도 / 간단 코멘트

“같은 드릴 다시하기” 버튼 → DrillRunScreen 재시작

“상세 기록 보기” → TrainingSessionDetailScreen 이동.

7. 히스토리 화면
history/training_history_screen.dart

역할:

유저의 최근 트레이닝 세션 목록 전체를 보여주는 리스트 화면.

trainingRecentSessionsProvider를 구독.

각 아이템 탭 → TrainingSessionDetailScreen으로 이동.

history/training_session_detail_screen.dart

역할:

단일 세션의 상세 분석 화면.

표시:

드릴 제목/ID

시작~종료 시간

성공률, 성공/시도

extra 필드(드릴 설정 정보)를 JSON처럼 보여주는 디버그용/정보용 카드.

8. 공용 UI 위젯
training_recommendation_card.dart

역할:

트레이닝 홈에서 쓰는 “추천 드릴/프로그램 카드 UI”.

티어/난이도/카테고리/간단 설명 + “바로 시작” 버튼 같은 것 포함.

neon_glow_container.dart

역할:

네온 느낌 나는 글로우 박스 컨테이너.

트레이닝/DAO 티어 영역 등에 포인트 UI로 사용.

dual_neon_gauge_row.dart

역할:

두 개의 게이지(예: Phoenix vs Live, HitRate vs 목표치)를
가로로 나란히 네온 스타일로 보여주는 위젯.

트레이닝 홈에서 시각화용.

dao_tier_badge_large.dart

역할:

현재 유저의 DAO 티어를 크게 보여주는 큰 배지 위젯.

티어명, 색상, 설명 등을 한 번에 보여주는 대표 아이콘 역할.

이렇게 보면 구조가 대충 이렇게야:

상수/유틸 → 드릴/프로그램/티어 정의

모델/레포지토리 → Firestore랑 데이터 통신

프로바이더 → 현재 세션 / 히스토리 / 홈 데이터 상태 관리

스크린 → 홈·입력·테스트·드릴 진행·결과·히스토리·상세

위젯 → 네온 카드/게이지/배지 같은 공용 UI


한 줄 요약

RunScreen에서 → 실제 던지기 + 라운드 입력

**Provider(Notifer)**가 → 세션 생성/업데이트 관리

Repository가 → Firestore와 통신

ResultScreen에서 → 한 세션에 대한 피드백 제공

History + DetailScreen에서 → 과거 기록을 타임라인처럼 보여줌

지금 구조는:

“V3 드릴/세션/히스토리 풀 체인이 앱 안에서 한 바퀴 도는 상태”

이라서,
이제 이 위에 추천 로직 / 티어업 연출 / 통계 대시보드를 얹으면 돼.
