1. “연습이 되고 있다”를 어떻게 정의할까?

연습 효과는 결국 세 가지 축이야:

드릴 단위 퍼포먼스

예:

T20 드릴 → T20 히트율 (T20 hits / 던진 다트)

크리켓 → MPR

더블 시계 → 각 더블당 성공까지 걸린 세트 수

체크아웃 드릴 → 세트 성공률(성공 세트 / 전체 세트)

Count-Up 계열 → 최종 점수

시간에 따른 변화(트렌드)

“한 번 잘 쏜 것”이 아니라

최근 5~10 세션 기준 우상향 / 횡보 / 하락

목표 구간에 도달했는지

이미 extraConfig 에 거의 다 들어가 있음:

targetHits, targetMprMin, targetMprMax,
targetScore, hintTargetSuccessRateMin …

이걸 기준으로

미달 / 목표 구간 / 초과
3단계 정도로 색칠해 줄 수 있어.

👉 즉,
“연습이 되고 있다” =

(1) 지금 퍼포먼스가 목표 구간에 어느 정도 근접해 있고,

(2) 과거 본인 기록 대비 나아지는 흐름이 보일 때.

2. 어떤 데이터를 세션에 반드시 남겨야 할까?

이미 training_session_model.dart 로 구조 잡아놨을 텐데,
“히스토리/그래프”까지 생각하면 최소 이건 있어야 해:

공통 필드 (이미 거의 있을 거라 봄)

userId

drillId

tierAtThatTime (그때의 DAO 트레이닝 티어)

createdAt (날짜/시간)

inputMode (hitCount / scoreOnly / cricketMarks…)

성과 지표 필드

totalDarts

hitCount (해당 드릴 의미에 맞게)

totalScore (Count-Up, 501 등)

totalMarks (크리켓 마크 전용이면)

successRate

ex) 더블 드릴: 성공세트 / 전체세트

체크아웃 드릴: 성공세트 / 전체세트

mpr, ppd 같은 게 필요하면 여기서/혹은 계산해서 저장

“정규화된 점수” 하나

정말 중요 포인트 하나:

각 드릴마다 다른 단위를
하나의 공통 점수(0~100점)로 변환해 두면
나중에 합치고 비교하기가 미친 듯이 편해진다.

예시:

T20 드릴:

목표: 60발 중 20개 이상(=33%)

내 히트율이 15개(25%)면

sessionScore = 25 / 33 ≒ 0.76 → 76점

크리켓 MPR 드릴 (targetMprMin ~ Max = 2.8~3.0):

내 MPR 2.9 → 100점

2.5 → 2.5 / 2.8 ≒ 0.89 → 89점

Count-Up 8R (650/700/720 milestone):

620점 → 650전 단계 → 60점

680점 → 650~700 구간 → 80점

720↑ → 100점

이렇게 드릴별 extraConfig 안에 있는 목표치들을 이용해서
각 세션마다 normalizedScore (0~100)를 계산해서 저장해 두는 거야.

3. 히스토리와 그래프는 어떻게 구성할까?
3-1. 세션 히스토리 화면 (이미 있는 history에 살 붙이기)

드릴별 탭 / 필터

“T20 집중”, “Cricket 풀보드”, “Count-Up” 등

각 드릴 선택 시:

최근 10세션 라인차트:

X축: 날짜

Y축: 해당 드릴 핵심 지표

T20 → T20 hit%

크리켓 → MPR

Count-Up → 점수

아래 리스트:

날짜, 핵심 값, 그날의 tier, 간단 배지 (예: 🔺상승, ➖유지, 🔻하락)

3-2. “전체 트레이닝 대시보드” 카드

training_home_screen 상단에:

이번 주 던진 다트 수

이번 주 세션 수

최근 10세션 평균 normalizedScore

지난 10세션 대비 변화:

+12점 → 초록 화살표

-5점 → 주황 화살표

“이번 주 많이 한 연습 TOP 3” (드릴명 + 횟수)

이 정도만 있어도
“아 내가 뭔가 쌓이고 있구나”를 체감할 수 있어.

4. 연습 기록 → 티어 / 레이팅과 어떻게 연결할까?

여기서 중요한 건:

실제 피닉스 / 라이브 레이팅은
앱이 바꿀 수 있는 영역이 아니고,
DAO Training Tier는 “트레이닝 전용 지표” 라는 것.

그래서 이렇게 나누는 걸 추천해.

4-1. DAO Training Tier = 트레이닝 기반 실력존

이미 정의한 7티어:

Beginner → Learner → Competitor → Challenger → Elite → Pro → Master

이건:

레벨테스트 / 레이팅 입력 시 초기값 잡고

이후 트레이닝 성적 기반으로 미세조정하는 구조로.

4-2. 티어 변동 로직 (V1은 단순하게 가자)

예시 로직:

기준: 최근 20세션

각 세션의 normalizedScore 평균을 구해서:

0 ~ 40: 현재 티어보다 1단계 아래를 추천

40 ~ 70: 현재 티어 유지

70 ~ 85: 현재 티어 유지 + 상위 티어 일부 드릴 오픈

85 이상: 상위 티어 승급 추천

여기서 “추천”만 하고
자동으로 티어를 바꾸지 말고:

“최근 20회 연습 결과
Challenger 상단~Elite 하단 구간입니다.
→ Elite 티어 드릴 일부가 열렸어요.”
이런 식으로 피드백 + 컨텐츠 오픈 정도로 시작.

나중에 안정화되면:

실제로 user.trainingTier 를 1단계 올리는 것도 가능.

5. “어디서부터 시작할까?” → 실제 작업 순서

지금 상태에서 내가 추천하는 실제 TODO 순서는 이거야:

STEP 1. “측정 지표” 확정

(대화로 먼저 확실히)

각 inputMode / 드릴 타입별로

이 드릴의 핵심 성과지표는 “이거 하나”라고 정하기

hitCount 계열 → hitRate

scoreOnly → finalScore

cricketMarks → MPR

checkout/finish → 세트 성공률

그리고 extraConfig 에 이미 있는 target 값 기준으로
0~100 점수를 어떻게 계산할지 간단한 규칙을 정리.

👉 이건 말/문서로 먼저 정리해도 되고,
원하면 내가 표로 정리해 줄 수도 있어.

STEP 2. training_session_model 에 성과 필드 + normalizedScore 추가

이미 있는 모델에:

double? normalizedScore;

double? mpr; (필요시)

double? ppd; (필요시)

finishSession() 안에서:

drill.extraConfig + 세션 raw 데이터로
normalizedScore 계산해서 세션에 저장.

이렇게 하면
나중에 그래프 만들 때도 그냥 이 값만 쓰면 돼.

STEP 3. 히스토리/그래프 화면 V1

너무 거창하게 말고, 가장 기본만:

training_history_screen 에서

드릴 선택 → 최근 10세션 불러오기

normalizedScore or 핵심 지표를 라인차트 하나로 보여주기

추가로 상단에:

최근 10세션 평균값

“이전 10세션 대비 +X / -Y” 숫자만 표시

이 정도면 “연습이 쌓이고 있다” 감이 바로 온다.

STEP 4. “트레이닝 티어 인사이트” 카드

training_home_screen 이나 my_page 에 카드 하나 추가:

현재 트레이닝 상태

최근 20세션 평균 점수: 74점

예상 실력 구간: Challenger ~ Elite

추천: Elite 드릴 ‘T20 집중 60발’ / ‘Cricket 파워 15R’ 우선 진행

이건 로직:

최근 20세션 불러오기

평균 normalizedScore

평균이 어느 구간인지 보고 “예상 티어 레인지” 텍스트만 계산

부족한 카테고리(예: 더블계가 점수가 낮음)를 보고
추천 드릴 2~3개 뽑기.

STEP 5. 나중 단계: 월간 스냅샷/배지

조금 더 발전된 버전으로는:

user_training_snapshots/{YYYY-MM} 같은 컬렉션 만들어서

그 달:

총 세션 수

총 던진 다트 수

평균 normalizedScore

가장 많이 한 드릴

이런 걸 Cloud Functions 로 요약해서 저장.

그리고:

“2025년 12월: 연습왕 배지 🏅(세션 30회 이상)”

“T20 성공률 10% → 28% 성장 📈”
이런 배지/요약 리포트도 가능.

정리하면

먼저 “측정”부터 정의하자.

어떤 드릴에서 무엇을 성공으로 볼 것인지.

그 다음 세션에 그 지표를 꼭 저장하고,

extraConfig 기반으로 normalizedScore까지 계산.

그걸 히스토리 + 간단한 차트로 보여주고,

마지막에 DAO Training Tier / 예상 실력 구간 / 추천 드릴에 연결하면 돼.

지금은 “데이터 수집 & 시각화 & 간단한 인사이트” 까지가 1차 목표,
그 다음 단계가 “티어 자동 조정 / 프로그램 자동 추천”이라고 보면 딱 좋을 것 같아.

원하면 다음 턴에

“드릴 타입별 normalizedScore 계산 규칙표”
하나 쫙 만들어줄게.
그거 기준으로 finishSession() 안에 넣으면 바로 돌아간다 💪
